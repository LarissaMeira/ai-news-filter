# Trusted Sources

Default sources for the AI News Filter. Users can customize this list via project instructions or by asking Claude to add/remove sources.

|---|---|---|
| OpenAI | releases, API updates, research | openai.com/blog |
| Anthropic | model launches, features, safety research | anthropic.com/news |
| Google DeepMind | research breakthroughs, Gemini updates | deepmind.google/blog |
| Meta AI (FAIR) | open-source releases, LLaMA updates | ai.meta.com/blog |
| Mistral | model releases, open-source updates | mistral.ai/news |
| Cohere | enterprise AI, RAG, embeddings | cohere.com/blog |
| Stability AI | image/video generation, open models | stability.ai/news |
